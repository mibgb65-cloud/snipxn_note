# Snipxn 数据库建表文档

**数据库**: PostgreSQL
**字符集**: UTF-8
**命名规范**: 表名/字段名全小写下划线，主键统一 UUID

```sql
-- 首先启用 UUID 扩展（整个数据库只需执行一次）
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
```

## 一、认证与用户模块

### 1.1 users（用户主表）

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| email | VARCHAR(255) | UNIQUE NOT NULL | — | 邮箱，唯一登录标识 |
| nickname | VARCHAR(50) | — | — | 昵称，新用户引导时填写 |
| avatar | VARCHAR(512) | — | — | 头像访问路径，格式 `/api/v1/files/{id}` |
| bio | VARCHAR(200) | — | — | 一句话简介 |
| gender | SMALLINT | — | 0 | 性别：0-未知 1-男 2-女 |
| birthday | DATE | — | — | 生日 |
| storage_limit | BIGINT | NOT NULL | 1073741824 | 云空间上限，默认 1 GB（单位：字节）|
| storage_used | BIGINT | NOT NULL | 0 | 已用空间（字节），上传文件时更新 |
| status | VARCHAR(20) | NOT NULL | 'ACTIVE' | 账号状态：ACTIVE / BANNED / LOCKED |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 注册时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后更新时间 |

```sql
CREATE TABLE users (
    id             UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    email          VARCHAR(255) UNIQUE NOT NULL,
    nickname       VARCHAR(50),
    avatar         VARCHAR(512),
    bio            VARCHAR(200),
    gender         SMALLINT     NOT NULL DEFAULT 0,
    birthday       DATE,
    storage_limit  BIGINT       NOT NULL DEFAULT 1073741824,
    storage_used   BIGINT       NOT NULL DEFAULT 0,
    status         VARCHAR(20)  NOT NULL DEFAULT 'ACTIVE',
    created_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_users_email ON users(email);
```

### 1.2 user_auths（登录方式表）

> 一个用户可绑定多种登录方式（密码、GitHub 等）。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 关联 users.id，用户删除级联删除 |
| identity_type | VARCHAR(20) | NOT NULL | — | 认证类型：PASSWORD / GITHUB / WECHAT / GOOGLE |
| identifier | VARCHAR(255) | NOT NULL | — | 标识符：密码登录存邮箱，第三方登录存 OpenID |
| credential | VARCHAR(255) | — | — | 凭证：密码登录存 BCrypt Hash，第三方可为空 |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 创建时间（即绑定时间） |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后更新时间 |

```sql
CREATE TABLE user_auths (
    id             UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id        UUID         NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    identity_type  VARCHAR(20)  NOT NULL,
    identifier     VARCHAR(255) NOT NULL,
    credential     VARCHAR(255),
    created_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW(),

    UNIQUE (identity_type, identifier)          -- 同一类型同一标识不能重复绑定
);

CREATE INDEX idx_user_auths_identifier ON user_auths(identifier);
```

### 1.3 user_settings（用户偏好配置表）

> 与 users 一对一，用 JSONB 存储灵活配置，避免频繁加列。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| user_id | UUID | PK FK | — | 关联 users.id，同时作为主键（一对一）|
| preferences | JSONB | NOT NULL | '{}' | 偏好配置，示例见下方 |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后更新时间 |

**preferences 示例结构：**
```json
{
  "theme": "dark",
  "language": "zh_CN",
  "sync_only_wifi": true,
  "code_font_size": 14
}
```

```sql
CREATE TABLE user_settings (
    user_id      UUID        PRIMARY KEY REFERENCES users(id) ON DELETE CASCADE,
    preferences  JSONB       NOT NULL DEFAULT '{}'::jsonb,
    updated_at   TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

### 1.4 user_devices（设备 Token 表）

> 管理多设备的 Refresh Token，支持踢下线。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 关联 users.id |
| device_name | VARCHAR(100) | — | — | 设备名，如 "Chrome Web" / "Pixel 7" |
| device_id | VARCHAR(100) | NOT NULL | — | 客户端生成的唯一设备指纹 |
| refresh_token_hash | VARCHAR(255) | NOT NULL | — | Refresh Token 的 SHA-256 哈希值（不存明文）|
| prev_refresh_token_hash | VARCHAR(255) | — | — | 上一次 Refresh Token 哈希，用于重放检测 |
| expires_at | TIMESTAMPTZ | NOT NULL | — | Token 过期时间（通常 7 天）|
| last_login_ip | VARCHAR(45) | — | — | 最近登录 IP（支持 IPv6）|
| last_login_at | TIMESTAMPTZ | NOT NULL | NOW() | 最近登录时间 |
| is_revoked | BOOLEAN | NOT NULL | false | 是否已吊销（踢下线后置 true）|
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后更新时间 |

```sql
CREATE TABLE user_devices (
    id                  UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id             UUID         NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    device_name         VARCHAR(100),
    device_id           VARCHAR(100) NOT NULL,
    refresh_token_hash       VARCHAR(255) NOT NULL,
    prev_refresh_token_hash  VARCHAR(255),
    expires_at               TIMESTAMPTZ  NOT NULL,
    last_login_ip       VARCHAR(45),
    last_login_at       TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    is_revoked          BOOLEAN      NOT NULL DEFAULT FALSE,
    created_at          TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at          TIMESTAMPTZ  NOT NULL DEFAULT NOW(),

    UNIQUE (user_id, device_id)
);
```

## 二、笔记核心模块

### 2.1 folders（文件夹表）

> 继承 SyncEntity，参与离线同步。每个用户有且仅有一个 `is_default=true` 的默认文件夹（Inbox），不可删除。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 所属用户 |
| name | VARCHAR(100) | NOT NULL | — | 文件夹名称 |
| icon | VARCHAR(50) | NOT NULL | 'folder' | 图标（Emoji 或内置图标 ID）|
| is_default | BOOLEAN | NOT NULL | false | 是否为默认文件夹（每用户唯一）|
| rank_index | VARCHAR(100) | — | — | LexoRank 排序字段，支持拖拽排序 |
| is_deleted | BOOLEAN | NOT NULL | false | 软删除标记 |
| version | BIGINT | NOT NULL | 1 | 乐观锁版本号，用于同步冲突检测 |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后更新时间 |

```sql
CREATE TABLE folders (
    id          UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id     UUID         NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name        VARCHAR(100) NOT NULL,
    icon        VARCHAR(50)  NOT NULL DEFAULT 'folder',
    is_default  BOOLEAN      NOT NULL DEFAULT FALSE,
    rank_index  VARCHAR(100),
    is_deleted  BOOLEAN      NOT NULL DEFAULT FALSE,
    version     BIGINT       NOT NULL DEFAULT 1,
    created_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_folders_user ON folders(user_id, rank_index)
    WHERE is_deleted = FALSE;             -- 只索引未删除的文件夹
```

### 2.2 notes（笔记表）

> 核心业务表，继承 SyncEntity。`content` 存储 Markdown 原文，`summary` 是去除 Markdown 符号后的纯文本摘要（后端自动截取前 200 字）。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 所属用户 |
| folder_id | UUID | FK NOT NULL | — | 所属文件夹，必须归属（不能为空）|
| title | VARCHAR(255) | NOT NULL | '无标题笔记' | 笔记标题 |
| content | TEXT | NOT NULL | '' | Markdown 正文 |
| summary | VARCHAR(200) | — | — | 纯文本摘要，列表页展示用，后端自动生成 |
| primary_language | VARCHAR(50) | — | — | 主编程语言，如 java / python，列表页显示图标 |
| is_starred | BOOLEAN | NOT NULL | false | 收藏状态 |
| is_deleted | BOOLEAN | NOT NULL | false | 回收站状态（软删除）|
| status | VARCHAR(20) | NOT NULL | 'NORMAL' | 扩展状态：NORMAL / ARCHIVED / LOCKED |
| version | BIGINT | NOT NULL | 1 | 乐观锁版本号，同步冲突检测 |
| last_device_id | VARCHAR(100) | — | — | 最后修改该笔记的设备 ID |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后修改时间 |

```sql
CREATE TABLE notes (
    id               UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id          UUID         NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    folder_id        UUID         NOT NULL REFERENCES folders(id),
    title            VARCHAR(255) NOT NULL DEFAULT '无标题笔记',
    content          TEXT         NOT NULL DEFAULT '',
    summary          VARCHAR(200),
    primary_language VARCHAR(50),
    is_starred       BOOLEAN      NOT NULL DEFAULT FALSE,
    is_deleted       BOOLEAN      NOT NULL DEFAULT FALSE,
    status           VARCHAR(20)  NOT NULL DEFAULT 'NORMAL',
    version          BIGINT       NOT NULL DEFAULT 1,
    last_device_id   VARCHAR(100),
    created_at       TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at       TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

-- 文件夹内笔记列表（最常用）
CREATE INDEX idx_notes_folder  ON notes(folder_id, updated_at DESC) WHERE is_deleted = FALSE;
-- 全局最近编辑
CREATE INDEX idx_notes_recent  ON notes(user_id, updated_at DESC)   WHERE is_deleted = FALSE;
-- 收藏列表
CREATE INDEX idx_notes_starred ON notes(user_id)                    WHERE is_starred = TRUE AND is_deleted = FALSE;
-- 回收站
CREATE INDEX idx_notes_trash   ON notes(user_id)                    WHERE is_deleted = TRUE;
```

### 2.3 tags（标签表）

> 用户自定义标签，继承 SyncEntity，名称在同一用户下唯一。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 所属用户 |
| name | VARCHAR(50) | NOT NULL | — | 标签名称，同一用户下唯一 |
| color | VARCHAR(20) | — | — | 标签颜色，如 `#7B3FE4` |
| is_deleted | BOOLEAN | NOT NULL | false | 软删除标记 |
| version | BIGINT | NOT NULL | 1 | 同步版本号 |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 创建时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后更新时间 |

```sql
CREATE TABLE tags (
    id         UUID        PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id    UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    name       VARCHAR(50) NOT NULL,
    color      VARCHAR(20),
    is_deleted BOOLEAN     NOT NULL DEFAULT FALSE,
    version    BIGINT      NOT NULL DEFAULT 1,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    UNIQUE (user_id, name)                      -- 同一用户下标签名不重复
);
```

### 2.4 note_tags（笔记-标签关联表）

> 多对多关联，联合主键。同步时将"笔记的全部标签 ID 列表"作为一个整体同步，不单独同步此表行。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| note_id | UUID | PK FK | 关联 notes.id，笔记删除级联删除 |
| tag_id | UUID | PK FK | 关联 tags.id，标签删除级联删除 |

```sql
CREATE TABLE note_tags (
    note_id UUID NOT NULL REFERENCES notes(id) ON DELETE CASCADE,
    tag_id  UUID NOT NULL REFERENCES tags(id)  ON DELETE CASCADE,

    PRIMARY KEY (note_id, tag_id)
);
```

### 2.5 deleted_records（软删除记录表）

> 专为增量同步设计。当 notes / folders / tags 被软删除时，在此表写入一条记录，供客户端 Pull 时获取"需要在本地删除哪些数据"。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 所属用户 |
| table_name | VARCHAR(50) | NOT NULL | — | 被删除数据所在表：notes / folders / tags |
| record_id | UUID | NOT NULL | — | 被删除记录的 ID |
| deleted_at | TIMESTAMPTZ | NOT NULL | NOW() | 删除时间，作为同步时间游标 |

```sql
CREATE TABLE deleted_records (
    id         UUID        PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id    UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    table_name VARCHAR(50) NOT NULL,
    record_id  UUID        NOT NULL,
    deleted_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);

-- 同步拉取时：WHERE user_id = ? AND deleted_at > last_pulled_at
CREATE INDEX idx_deleted_sync ON deleted_records(user_id, deleted_at);
```

### 2.6 user_files（用户文件表）

> 图片直接以 BYTEA 存入 PostgreSQL（毕设方案，无需 OSS）。访问路径由后端根据 id 生成。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键，同时作为访问路径的标识符 |
| user_id | UUID | FK NOT NULL | — | 上传者 |
| file_name | VARCHAR(255) | NOT NULL | — | 原始文件名，如 `screenshot.png` |
| file_type | VARCHAR(50) | NOT NULL | — | MIME 类型：image/jpeg / image/png / image/gif / image/webp |
| file_size | BIGINT | NOT NULL | — | 文件大小（字节），用于计算配额 |
| file_data | BYTEA | NOT NULL | — | 文件二进制内容 |
| uploaded_at | TIMESTAMPTZ | NOT NULL | NOW() | 上传时间 |

> 访问方式：`GET /api/v1/files/{id}`，后端读取 `file_data` 以 `file_type` 作为 `Content-Type` 返回。
> Markdown 插入语法：`![描述](/api/v1/files/{id})`

```sql
CREATE TABLE user_files (
    id          UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id     UUID         NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    file_name   VARCHAR(255) NOT NULL,
    file_type   VARCHAR(50)  NOT NULL,
    file_size   BIGINT       NOT NULL,
    file_data   BYTEA        NOT NULL,
    uploaded_at TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

-- 配额统计：SELECT SUM(file_size) FROM user_files WHERE user_id = ?
CREATE INDEX idx_files_user ON user_files(user_id);
```

## 三、社区模块

### 3.1 posts（社区帖子表）

> 帖子是私有笔记内容的公开快照，发布后 `content` 不会随原笔记变化。`view_count` 由 RabbitMQ 异步更新。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 作者 |
| origin_note_id | UUID | FK | — | 关联的私有笔记 ID（可为空，笔记删除后置 NULL）|
| title | VARCHAR(255) | NOT NULL | — | 帖子标题 |
| content | TEXT | NOT NULL | — | 发布时的 Markdown 内容快照 |
| language | VARCHAR(50) | — | — | 编程语言分类，如 Java / Python |
| tags | JSONB | — | '[]' | 标签列表，如 `["React", "CSS"]` |
| view_count | BIGINT | NOT NULL | 0 | 浏览量，MQ 异步更新 |
| like_count | BIGINT | NOT NULL | 0 | 点赞数 |
| collect_count | BIGINT | NOT NULL | 0 | 收藏数 |
| comment_count | BIGINT | NOT NULL | 0 | 评论数（预留）|
| status | VARCHAR(20) | NOT NULL | 'PUBLISHED' | 状态：PUBLISHED / HIDDEN |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 发布时间 |
| updated_at | TIMESTAMPTZ | NOT NULL | NOW() | 最后更新时间 |

```sql
CREATE TABLE posts (
    id             UUID         PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id        UUID         NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    origin_note_id UUID         REFERENCES notes(id) ON DELETE SET NULL,
    title          VARCHAR(255) NOT NULL,
    content        TEXT         NOT NULL,
    language       VARCHAR(50),
    tags           JSONB        NOT NULL DEFAULT '[]'::jsonb,
    view_count     BIGINT       NOT NULL DEFAULT 0,
    like_count     BIGINT       NOT NULL DEFAULT 0,
    collect_count  BIGINT       NOT NULL DEFAULT 0,
    comment_count  BIGINT       NOT NULL DEFAULT 0,
    status         VARCHAR(20)  NOT NULL DEFAULT 'PUBLISHED',
    created_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW(),
    updated_at     TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);

-- 最新 Feed 流
CREATE INDEX idx_posts_latest   ON posts(created_at DESC)               WHERE status = 'PUBLISHED';
-- 热门榜单
CREATE INDEX idx_posts_trending ON posts(view_count DESC, like_count DESC) WHERE status = 'PUBLISHED';
-- 某用户的所有帖子
CREATE INDEX idx_posts_user     ON posts(user_id, created_at DESC);
```

### 3.2 user_follows（关注关系表）

> 联合主键天然防止重复关注，无需额外唯一索引。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| follower_id | UUID | PK FK | — | 粉丝（发起关注的人）|
| following_id | UUID | PK FK | — | 博主（被关注的人）|
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 关注时间 |

```sql
CREATE TABLE user_follows (
    follower_id  UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    following_id UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    created_at   TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    PRIMARY KEY (follower_id, following_id),

    CONSTRAINT no_self_follow CHECK (follower_id <> following_id)   -- 不能关注自己
);

-- 查"我关注了谁"（关注列表）
CREATE INDEX idx_follows_follower  ON user_follows(follower_id);
-- 查"谁关注了我"（粉丝列表 / 粉丝数）
CREATE INDEX idx_follows_following ON user_follows(following_id);
```

### 3.3 interactions（互动记录表）

> 统一存储点赞（LIKE）和收藏（COLLECT）行为，唯一约束防止重复操作。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK NOT NULL | — | 操作用户 |
| target_id | UUID | NOT NULL | — | 目标 ID（帖子 ID）|
| target_type | VARCHAR(20) | NOT NULL | — | 目标类型：POST（预留扩展 COMMENT）|
| action_type | VARCHAR(20) | NOT NULL | — | 操作类型：LIKE / COLLECT |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 操作时间 |

```sql
CREATE TABLE interactions (
    id          UUID        PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id     UUID        NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    target_id   UUID        NOT NULL,
    target_type VARCHAR(20) NOT NULL,
    action_type VARCHAR(20) NOT NULL,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),

    UNIQUE (user_id, target_id, action_type)    -- 同一用户对同一目标只能点赞/收藏一次
);

-- 查某用户是否点赞/收藏了某帖子
CREATE INDEX idx_interactions_user ON interactions(user_id, target_id, action_type);
```

## 四、运维与反馈模块

### 4.1 feedbacks（用户反馈表）

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | UUID | PK | uuid_generate_v4() | 主键 |
| user_id | UUID | FK | — | 提交用户（允许为 NULL，支持匿名反馈）|
| content | TEXT | NOT NULL | — | 反馈内容 |
| contact | VARCHAR(100) | — | — | 联系方式（邮箱或手机，选填）|
| images | JSONB | — | '[]' | 截图文件路径列表，如 `["/api/v1/files/{id}"]` |
| status | VARCHAR(20) | NOT NULL | 'PENDING' | 处理状态：PENDING / PROCESSING / RESOLVED |
| admin_reply | TEXT | — | — | 管理员回复内容 |
| created_at | TIMESTAMPTZ | NOT NULL | NOW() | 提交时间 |

```sql
CREATE TABLE feedbacks (
    id          UUID        PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id     UUID        REFERENCES users(id) ON DELETE SET NULL,
    content     TEXT        NOT NULL,
    contact     VARCHAR(100),
    images      JSONB       NOT NULL DEFAULT '[]'::jsonb,
    status      VARCHAR(20) NOT NULL DEFAULT 'PENDING',
    admin_reply TEXT,
    created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```

### 4.2 app_versions（App 版本管理表）

> 用于 Android 客户端检查更新，支持强制升级。

| 字段 | 类型 | 约束 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | SERIAL | PK | 自增 | 主键（版本记录用自增即可）|
| platform | VARCHAR(20) | NOT NULL | — | 平台：ANDROID / IOS |
| version_code | INT | NOT NULL | — | 内部版本号，如 102（用于比较大小）|
| version_name | VARCHAR(20) | NOT NULL | — | 展示版本号，如 "1.0.2" |
| download_url | VARCHAR(512) | — | — | APK 下载地址或应用商店链接 |
| update_log | TEXT | — | — | 更新日志（支持 Markdown）|
| force_update | BOOLEAN | NOT NULL | false | 是否强制更新（低于此版本必须升级）|
| released_at | TIMESTAMPTZ | NOT NULL | NOW() | 发布时间 |

```sql
CREATE TABLE app_versions (
    id           SERIAL       PRIMARY KEY,
    platform     VARCHAR(20)  NOT NULL,
    version_code INT          NOT NULL,
    version_name VARCHAR(20)  NOT NULL,
    download_url VARCHAR(512),
    update_log   TEXT,
    force_update BOOLEAN      NOT NULL DEFAULT FALSE,
    released_at  TIMESTAMPTZ  NOT NULL DEFAULT NOW()
);
```

## 五、表关系汇总

```
users (1) ──── (N) user_auths        用户可绑定多种登录方式
users (1) ──── (1) user_settings     用户偏好配置（一对一）
users (1) ──── (N) user_devices      多设备 Token 管理
users (1) ──── (N) folders           用户创建的文件夹
users (1) ──── (N) user_files        用户上传的图片文件
folders (1) ── (N) notes             文件夹包含多篇笔记
users (1) ──── (N) tags              用户创建的标签
notes (N) ──── (M) tags              通过 note_tags 关联（多对多）
notes (1) ──── (N) deleted_records   软删除同步记录
users (1) ──── (N) posts             用户发布的社区帖子
notes (1) ──── (0..1) posts          帖子可关联源笔记（发布时快照）
users (N) ──── (M) users             通过 user_follows 互关
users (1) ──── (N) interactions      点赞 / 收藏记录
```
