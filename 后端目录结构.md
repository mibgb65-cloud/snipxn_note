# Snipxn 后端工程目录结构

**工程根目录**: `E:/biyeshiji/Snipxn_System/`
**构建工具**: Maven 多模块（Multi-Module）
**基础包名**: `com.snipxn`
**ORM**: MyBatis Plus 3.5.15

---

## 一、模块总览

```
Snipxn_System/
├── pom.xml              ← 父工程，packaging: pom，统一管理依赖版本
│
├── snipxn-common/       ← 公共基础（BaseEntity、Result、ErrorCode）
├── snipxn-auth/         ← 认证与用户模块
├── snipxn-note/         ← 笔记核心模块（含文件上传）
├── snipxn-community/    ← 社区模块
├── snipxn-sandbox/      ← 代码沙盒模块
└── snipxn-app/          ← 启动聚合模块（Spring Boot 主入口）
```

**模块依赖关系：**

```
snipxn-common
    ↑
snipxn-auth ──────────────────────────────────┐
    ↑                                          ↓
snipxn-note                           snipxn-community
    ↑                                          ↑
snipxn-sandbox                        snipxn-app（聚合所有）
```

## 二、各模块详细结构

### 2.1 snipxn-common（公共基础模块）

> 不含 Spring Boot 启动类，仅提供基础类供其他模块依赖。

```
snipxn-common/
├── pom.xml
└── src/main/java/com/snipxn/common/
    │
    ├── base/                                   # 基础实体
    │   ├── BaseEntity.java                     # id + createTime + updateTime（MP 自动填充）
    │   └── SyncEntity.java                     # extends BaseEntity，加 deleted + version
    │
    ├── result/                                 # 统一响应
    │   ├── Result.java                         # {code, message, data}，支持泛型
    │   └── PageResult.java                     # {total, list}，分页专用
    │
    └── exception/                              # 异常体系
        ├── ErrorCode.java                      # 错误码枚举（含 code + message）
        ├── BusinessException.java              # 运行时业务异常，持有 ErrorCode
        └── GlobalExceptionHandler.java         # @RestControllerAdvice，统一捕获异常
```

### 2.2 snipxn-auth（认证与用户模块）

> 负责用户注册/登录、JWT 签发、邮件验证码、用户资料管理。

```
snipxn-auth/
├── pom.xml                                     # 依赖 snipxn-common
└── src/main/java/com/snipxn/auth/
    │
    ├── entity/                                 # MP 实体（@TableName）
    │   ├── User.java                           # 用户主表（extends BaseEntity）
    │   ├── UserAuth.java                       # 登录方式表（PASSWORD / GITHUB）
    │   ├── UserDevice.java                     # 设备 RefreshToken 表
    │   └── UserSettings.java                   # 用户偏好配置（JSON）
    │
    ├── mapper/                                 # MP Mapper 接口（extends BaseMapper<T>）
    │   ├── UserMapper.java
    │   ├── UserAuthMapper.java
    │   ├── UserDeviceMapper.java
    │   └── UserSettingsMapper.java
    │
    ├── dto/
    │   ├── req/                                # 入参 DTO
    │   │   ├── SendCodeRequest.java            # 发送验证码：{email}
    │   │   ├── LoginRequest.java               # 登录：{email, code/password, deviceId}
    │   │   ├── RefreshTokenRequest.java        # 刷新 Token：{refreshToken, deviceId}
    │   │   ├── UpdateProfileRequest.java       # 更新资料：{nickname, bio, gender, birthday}
    │   │   └── SetPasswordRequest.java         # 设置/修改密码：{password}
    │   └── resp/                               # 出参 DTO
    │       ├── LoginResponse.java              # {accessToken, refreshToken, isNewUser, userInfo}
    │       ├── TokenResponse.java              # {accessToken, refreshToken}
    │       └── UserInfoResponse.java           # {id, nickname, avatar, bio, storageUsed, storageLimit}
    │
    ├── service/
    │   ├── AuthService.java                    # 接口（extends IService<User>）
    │   ├── UserService.java
    │   ├── EmailService.java
    │   └── impl/
    │       ├── AuthServiceImpl.java            # extends ServiceImpl<UserMapper, User>
    │       ├── UserServiceImpl.java
    │       └── EmailServiceImpl.java           # 发布 MQ 消息（不直接发邮件）
    │
    ├── controller/
    │   ├── AuthController.java                 # POST /auth/send-code, /auth/login,
    │   │                                       #      /auth/refresh, /auth/logout,
    │   │                                       # PUT  /auth/password
    │   └── UserController.java                 # PUT  /users/profile
    │                                           # GET  /users/{id}（个人主页）
    │
    ├── security/                               # JWT 相关
    │   ├── JwtUtil.java                        # 生成 / 解析 / 校验 Access Token
    │   ├── JwtAuthFilter.java                  # OncePerRequestFilter：从 Header 解析 Token 注入 Context
    │   └── CustomUserDetails.java              # UserDetails 实现，持有 userId + email
    │
    └── mq/
        ├── message/
        │   └── EmailMessage.java               # {to, code}  邮件消息体
        └── consumer/
            └── EmailConsumer.java              # @RabbitListener("email.send")，调用 JavaMailSender 发邮件
```

### 2.3 snipxn-note（笔记核心模块）

> 负责文件夹、笔记、标签、离线同步、图片上传（存库）。

```
    │   ├── Note.java                           # extends SyncEntity，含 content(TEXT)
    │   ├── Tag.java                            # extends SyncEntity
    │   ├── NoteTag.java                        # 多对多关联表，联合主键（noteId + tagId）
    │   ├── DeletedRecord.java                  # 软删除记录（同步专用）
    │   └── UserFile.java                       # 图片文件，含 fileData(byte[])（extends BaseEntity）
    │
    ├── mapper/                                 # MP Mapper 接口（extends BaseMapper<T>）
    │   ├── FolderMapper.java
    │   ├── NoteMapper.java
    │   ├── TagMapper.java
    │   ├── NoteTagMapper.java
    │   ├── DeletedRecordMapper.java
    │   └── UserFileMapper.java
    │
    ├── dto/
    │   ├── req/
    │   │   ├── CreateFolderRequest.java        # {name, icon}
    │   │   ├── UpdateFolderRequest.java        # {name, icon, rankIndex}
    │   │   ├── CreateNoteRequest.java          # {folderId, title}
    │   │   ├── UpdateNoteRequest.java          # {title, content, tags, version, primaryLanguage}
    │   │   └── SyncPushRequest.java            # {changes: {notes, folders, tags}}
    │   └── resp/
    │       ├── FolderResponse.java             # {id, name, icon, noteCount, rankIndex}
    │       ├── NoteListItemResponse.java       # {id, title, summary, primaryLanguage, updatedAt}（不含 content）
    │       ├── NoteDetailResponse.java         # {id, title, content, tags, version, ...}
    │       ├── SyncPullResponse.java           # {changes, timestamp}
    │       └── UploadResponse.java             # {fileId, url: "/api/v1/files/{id}", fileSize}
    │
    ├── service/
    │   ├── FolderService.java
    │   ├── NoteService.java
    │   ├── TagService.java
    │   ├── SyncService.java
    │   ├── FileService.java
    │   └── impl/
    │       ├── FolderServiceImpl.java          # extends ServiceImpl<FolderMapper, Folder>
    │       ├── NoteServiceImpl.java            # 乐观锁版本控制（@Version），自动摘要截取
    │       ├── TagServiceImpl.java
    │       ├── SyncServiceImpl.java            # Pull/Push 增量同步逻辑
    │       └── FileServiceImpl.java            # 校验 MIME + 配额 → 存 byte[] → 返回访问 URL
    │
    └── controller/
        ├── FolderController.java               # GET/POST  /folders
        │                                       # PUT/DELETE /folders/{id}
        ├── NoteController.java                 # GET/POST  /notes
        │                                       # GET/PUT/DELETE /notes/{id}
        │                                       # PUT /notes/{id}/star, /notes/{id}/restore
        ├── SyncController.java                 # GET  /sync/pull
        │                                       # POST /sync/push
        └── UploadController.java               # POST /upload/image
                                                # POST /upload/avatar
                                                # GET  /files/{id}（响应图片二进制，设置 Content-Type）
```

```
    │   ├── Post.java                           # 社区帖子（extends BaseEntity）
    │   ├── UserFollow.java                     # 关注关系（联合主键：followerId + followingId）
    │   └── Interaction.java                    # 点赞/收藏记录（userId + targetId + actionType）
    │
    ├── mapper/                                 # MP Mapper 接口（extends BaseMapper<T>）
    │   ├── PostMapper.java
    │   ├── UserFollowMapper.java
    │   └── InteractionMapper.java
    │
    ├── dto/
    │   ├── req/
    │   │   └── CreatePostRequest.java          # {title, content, language, tags, originNoteId?}
    │   └── resp/
    │       ├── PostListItemResponse.java       # 列表摘要（不含完整 content）
    │       └── PostDetailResponse.java         # 完整帖子（含 isLiked, isCollected）
    │
    ├── service/
    │   ├── PostService.java
    │   ├── InteractionService.java
    │   └── impl/
    │       ├── PostServiceImpl.java            # extends ServiceImpl<PostMapper, Post>
    │       │                                   # 发布 / Feed / 热门榜单，发布浏览量 MQ 消息
    │       └── InteractionServiceImpl.java     # 点赞 / 收藏的幂等写入与撤销，更新计数字段
    │
    ├── controller/
    │   ├── PostController.java                 # POST     /posts（发布）
    │   │                                       # GET      /posts/feed（Feed 流）
    │   │                                       # GET      /posts/{id}（详情，记录浏览）
    │   │                                       # POST/DEL /posts/{id}/like
    │   │                                       # POST/DEL /posts/{id}/collect
    │   └── FollowController.java               # POST/DEL /users/{id}/follow
    │                                           # GET      /users/{id}/followers
    │                                           # GET      /users/{id}/following
    │
    └── mq/
        ├── message/
        │   └── ViewCountMessage.java           # {postId, increment}
        └── consumer/
            └── ViewCountConsumer.java          # @RabbitListener("stats.view.update")
                                                # 批量异步更新 post.view_count，避免高并发写库
```

### 2.6 snipxn-app（启动聚合模块）

> 唯一含 `main()` 方法的模块，聚合所有业务模块并集中管理 Spring 配置。

```
snipxn-app/
├── pom.xml                                     # 依赖 snipxn-auth / note / community / sandbox
└── src/
    ├── main/
    │   ├── java/com/snipxn/
    │   │   ├── SnipxnApplication.java          # @SpringBootApplication
    │   │   │                                   # @MapperScan("com.snipxn.**.mapper")
    │   │   │
    │   │   └── config/
    │   │       ├── SecurityConfig.java         # Security 过滤链：白名单放行 + JwtAuthFilter 注入
    │   │       ├── RedisConfig.java            # RedisTemplate<String, Object> + Jackson 序列化
    │   │       ├── RabbitConfig.java           # Exchange / Queue / Binding Bean 声明
    │   │       └── SwaggerConfig.java          # SpringDoc 全局信息 + Bearer Token 鉴权头
    │   │
    │   └── resources/
    │       ├── application.yml                 # 公共配置（DB / Redis / RabbitMQ / MP / 业务参数）
    │       ├── application-dev.yml             # 开发环境覆盖（本地数据库、关闭限流等）
    │       ├── application-prod.yml            # 生产环境（从环境变量注入所有敏感配置）
    │       └── db/migration/                   # Flyway 迁移脚本（V1__init_schema.sql ...）
    │
    └── test/
        └── java/com/snipxn/
            └── ...                             # 集成测试
```

## 三、关键设计说明

| 设计点 | 说明 |
|--------|------|
| **ORM** | MyBatis Plus 3.5.15，Mapper 接口继承 `BaseMapper<T>`，ServiceImpl 继承 `ServiceImpl<M, T>` |
| **Service 接口 + impl 分离** | 接口放在 `service/` 根目录，实现类统一放 `service/impl/` |
| **DTO 命名规范** | 入参以 `Request` 结尾，出参以 `Response` 结尾，放在 `dto/req/` 和 `dto/resp/` 下 |
| **基础实体两层继承** | `BaseEntity`（通用）→ `SyncEntity`（加 deleted + version，仅离线同步实体继承）|
| **逻辑删除** | MP 全局配置 `logic-delete-field: deleted`，统一用 0/1 标记 |
| **MapperScan** | 启动类 `@MapperScan("com.snipxn.**.mapper")` 统一扫描所有模块 Mapper |
| **数据库迁移** | Flyway 管理，脚本放 `db/migration/`，命名规范 `V{n}__{description}.sql` |
| **文件存库** | 图片以 `byte[]` 存入 PostgreSQL，通过 `GET /files/{id}` 接口流式返回，不依赖 OSS |
| **浏览量异步更新** | 帖子详情接口不直接写库，而是发 MQ 消息，由 `ViewCountConsumer` 批量更新，防止写热点 |
| **配置集中在 snipxn-app** | Security / Redis / RabbitMQ 等配置统一在启动模块，业务模块只关注业务逻辑 |
| **Security 白名单** | `/auth/**`、`/files/**`（图片）、`/swagger-ui/**` 放行，其余需 Bearer Token |
